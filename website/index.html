Learn from demonstrated motion

Paired end-effector and joint observations teach local joint increments, conditioned on how the robot is already moving.

2

Decode in two calls

A history-conditioned MIP model makes an initial prediction, then a second prediction using the first result. The final increment is added to the measured joints.

⌁

Use geometry during training

An optional differentiable FK objective connects joint predictions to end-effector targets. Deployment uses the learned decoder without an online FK optimization loop.

Quick start
git clone https://github.com/RedAmancy918/MimicIK.git
cd MimicIK
python -m venv .venv
source .venv/bin/activate
pip install -e .

python -m mimicik.download \
  --model airbot --output checkpoints/airbot
python examples/infer.py \
  --checkpoint checkpoints/airbot
Python 3.11+ · PyTorch · NumPy · safetensors

The example uses synthetic inputs and sends no robot commands. Training and FK dependencies: pip install -e '.[train,fk]'. See the reproducibility notes for data and evaluation conventions.
